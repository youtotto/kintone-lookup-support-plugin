# ルックアップサポート（Lookup Support）

ルックアップフィールドの関係を見やすくし、基本的な自動取得まで行う無料の kintone プラグインです。

- 🎨 PC のレコード詳細画面で、ルックアップフィールドとコピー先フィールドを同じ色で表示
- ⚡ レコードの追加・編集画面でルックアップを自動取得（取得タイミングを選択可能）
- 🆓 無料・MIT License

---

## カラーマーカー

- **PC のレコード詳細画面のみ** で表示します
- ルックアップフィールドと、そのコピー先フィールドを同じ色で表示します（薄い背景と左側の色帯）
- 複数のルックアップにそれぞれ別の色を設定できます（6 色）
- ルックアップごとに ON / OFF を切り替えられます
- レコードの追加画面・編集画面・モバイル版では表示しません

---

## 自動取得

レコードの追加・編集画面（PC / モバイル）を開いたとき、ルックアップの「取得」を自動で実行します。ルックアップごとに取得タイミングを選べます。キーが空のときは、どのモードでも取得しません。取得は kintone 標準の自動取得で行われ、参照先が 1 件に特定できる場合にだけ値が入ります。

### コピー先が空のときだけ（既定）
次の 3 つをすべて満たすときだけ取得します。
- ルックアップのキーに値がある
- コピー先フィールドが 1 件以上ある
- コピー先フィールドがすべて空

入力済みの値を上書きしません。コピー先フィールドが設定されていないルックアップでは取得しません。

### 常に取得
キーに値があれば、追加・編集画面を開くたびに取得します。**コピー先を手修正している場合、その値は参照先の最新値で上書きされます。**

### 新規作成時のみ
追加画面（レコードをコピーして作成した場合を含む）でだけ取得します。編集画面では取得しません。

---

## 設定画面

- ルックアップごとに 1 枚のカードで、カラーマーカーと自動取得を設定します
- フォームから削除されたルックアップの設定は「フォームに見つかりません」と表示され、明示的に削除するまで保持されます
- 保存後は「アプリを更新」で反映されます

---

## 対象外（本プラグインでは行いません）

- 追加・編集画面・モバイル版でのカラーマーカー表示
- サブテーブル内のルックアップ（設定画面に件数だけ表示します）
- 条件付きの自動取得
- 参照元レコードとの差分表示

条件付き自動取得、テーブル内のルックアップ取得、参照元との差分表示は「ルックアップサポート＋」で利用できます。

---

## 使い方

1. kintone の「プラグイン」管理画面から本プラグインを読み込み、対象アプリに追加します
2. アプリの設定 → プラグイン → 本プラグインの「設定」で、ルックアップごとに色と自動取得を設定して「保存」します
3. 「アプリを更新」で反映します

---

## 対応環境

- kintone PC 版（レコード詳細画面、レコード追加・編集画面、プラグイン設定画面）
- kintone モバイル版（レコード追加・編集画面の自動取得のみ）
- ゲストスペースのアプリに対応

---

## 旧版（Lookup Color Marker / Lookup Color Marker Plus）からの移行

本プラグインは「Lookup Color Marker」「Lookup Color Marker Plus」と **同一のプラグイン ID** を引き継いでいます。

- 本プラグインの ZIP を読み込むと、旧版はそのまま本プラグインに置き換わり、保存済みの設定（色・ON / OFF・自動取得の有無）を引き継ぎます
- Lookup Color Marker の設定: 自動取得は無効のまま引き継ぎます
- Lookup Color Marker Plus で自動取得を ON にしていたルックアップは、取得タイミング **「常に取得」** として引き継ぎます。「常に取得」はコピー先の手修正を上書きする可能性があるため、必要に応じて設定画面で **「コピー先が空のときだけ」** へ変更してください
- 同じプラグイン ID のため、ルックアップサポート＋を使っている環境に本プラグインを読み込むと＋が置き換わります
